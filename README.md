# Trust Wallet Help Center

Static HTML landing page ready for GitHub Pages or Vercel.

## Files
- `index.html` — website
- `vercel.json` — Vercel configuration

## GitHub
Upload the files to a repository. For GitHub Pages, enable Pages from the repository settings and use the main branch/root.

## Vercel
Import the repository into Vercel. No build command is required for this static page.
